#+TITLE: Typst CV with Brilliant-CV
#+AUTHOR: Stefan Lendl

* Overview

A professional CV and cover letter built with [[https://typst.app][Typst]] using the [[https://typst.app/universe/package/brilliant-cv/][brilliant-cv]] template for the CV and [[https://typst.app/universe/package/letter-pro/][letter-pro]] (DIN 5008) for the cover letter.

* Requirements

- [[https://typst.app][Typst]] compiler
- [[https://just.systems][Just]] command runner
- Fonts (see [[#fonts][Fonts]] section)

* Quick Start

#+begin_src bash
just           # Compile CV to PDF
just watch     # Watch mode with auto-recompile
just open      # Compile and open in browser
#+end_src

* Project Structure

#+begin_example

* Configuration

All personal information and layout settings are in =profile_en/metadata.toml=:

- =header_quote=, =cv_footer= - Tagline under the header, footer text
- =[personal]= - Name, contact info, social links
- =[layout]= - Colors, fonts, spacing
- =[inject]= - Hidden ATS keywords
- =[custom]= - Sender address for the cover letter

* Commands

| Command             | Description                    |
|---------------------+--------------------------------|
| =just=              | Compile CV (default)           |
| =just check=        | Type-check without output      |
| =just watch=        | Watch and auto-recompile       |
| =just open=         | Compile and open PDF           |
| =just letter=       | Compile cover letter           |
| =just watch-letter= | Watch cover letter             |
| =just fmt=          | Format .typ and .toml files    |
| =just fmt-check=    | Fail on unformatted files      |

* Cover Letter

The cover letter uses [[https://typst.app/universe/package/letter-pro/][letter-pro]] with DIN 5008 formatting. Sender info is pulled from =profile_en/metadata.toml=, while per-letter content is kept in =letter-content.typ= (gitignored). To set up:

#+begin_src bash
cp letter-content.example.typ letter-content.typ
#+end_src

Edit =letter-content.typ= with recipient, subject, language, and the letter body:

#+begin_src typst
#let language = "de"  // optional, defaults to "en"

#let recipient = [
  ACME Corp\
  123 Main St\
  1010 Vienna
]
#let subject = "Application: Software Engineer"

Dear Hiring Manager,
...
#+end_src

Then compile with =just letter=.

* Fonts

The template requires several fonts. Install the following fonts on your system
or use the nix devShell which installs the fonts already

- Source Sans 3 (body text)
- Roboto (headers)
- Font Awesome 7 (icons)

* Profiles

Each =profile_<name>/= directory is a complete, self-contained CV: its own
=metadata.toml= plus all content modules. =en= is the default; select another at
compile time:

#+begin_src bash
typst compile cv.typ --input profile=de
#+end_src

To add a profile (a translation, or a variant tailored to one kind of role),
copy =profile_en/= to =profile_<name>/= and edit it. Profiles share nothing, so
a change to one is not reflected in the others. The cover letter always reads
=profile_en/metadata.toml=.

* Updating Typst Packages

The nix devShell provides brilliant-cv and letter-pro from nixpkgs
(=typst.withPackages= in =flake.nix=), so builds never download packages and
the versions are pinned by =flake.lock=. The version in each
=#import "@preview/..."= line must match the one nixpkgs provides; otherwise
the build fails with a =Read-only file system= error.

To upgrade:

#+begin_src bash
nix flake update
nix eval --raw --inputs-from . nixpkgs#typstPackages.brilliant-cv.version
#+end_src

Then set that version in the imports of =cv.typ= and every =profile_en/*.typ=
(and =letter.typ= for letter-pro). Outside the devShell, typst downloads
whatever version the imports name.

* Github Action and Releases

The Github action is set up so that it creates a release on every push on ~main~
but only a single release per day to avoid noise if there are several pushes in
a single edit session on one day.

Old releases are deleted because we don't need old CVs.

The permanent link for the latest release is:

https://github.com/stfl/cv/releases/latest/download/Stefan-Lendl-CV.pdf
