#+TITLE: Typst CV with Brilliant-CV
#+AUTHOR: Stefan Lendl

* Overview

A professional CV and cover letter built with [[https://typst.app][Typst]] using the [[https://typst.app/universe/package/brilliant-cv/][brilliant-cv]] template.

* Requirements

- [[https://typst.app][Typst]] compiler
- [[https://just.systems][Just]] command runner
- Fonts (see [[#fonts][Fonts]] section)

* Quick Start

#+begin_src bash
just           # Compile CV to PDF
just watch     # Watch mode with auto-recompile
just open      # Compile and open in browser
#+end_src

* Project Structure

#+begin_example
.
├── cv.typ              # Main CV document
├── letter.typ          # Cover letter
├── metadata.toml       # Personal info, layout, colors
├── modules_en/         # English content modules
│   ├── education.typ
│   ├── professional.typ
│   ├── skills.typ
│   ├── projects.typ
│   ├── certificates.typ
│   └── publications.typ
└── assets/
    ├── avatar.jpg      # Profile photo
    └── logos/          # Organization logos
#+end_example

* Configuration

All personal information and layout settings are in =metadata.toml=:

- =[personal]= - Name, contact info, social links
- =[layout]= - Colors, fonts, spacing
- =[lang.en]= - Header quote, footer text

* Commands

| Command             | Description                    |
|---------------------+--------------------------------|
| =just=              | Compile CV (default)           |
| =just check=        | Type-check without output      |
| =just watch=        | Watch and auto-recompile       |
| =just open=         | Compile and open PDF           |
| =just letter=       | Compile cover letter           |
| =just watch-letter= | Watch cover letter             |

* Fonts
:PROPERTIES:
:CUSTOM_ID: fonts
:END:

The template requires several fonts. Install the following fonts on your system
or use the nix devShell which installs the fonts already

- Source Sans 3 (body text)
- Roboto (headers)
- Font Awesome (icons)

* Multi-language Support

Set the language in =metadata.toml=:

#+begin_src toml
language = "en"  # Uses modules_en/
#+end_src

Create corresponding module directories (=modules_de/=, =modules_fr/=, etc.) with translated content.
